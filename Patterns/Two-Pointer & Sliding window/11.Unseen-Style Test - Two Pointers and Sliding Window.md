# Unseen-Style Test - Two Pointers and Sliding Window

Do not look for a pattern name first. For each problem, submit only:

1. Problem stripped of story
2. Brute-force idea
3. Bottleneck
4. Structural clues
5. Suspected pattern
6. Invariant
7. Data structure or state
8. Expected complexity

Do not code until those eight answers are complete.

## Problem 1

A monitoring system records one integer measurement per minute. For every block of exactly k consecutive minutes, calculate its average and return the largest average.

Constraints:

- 1 <= k <= n
- values may be negative
- the answer may be fractional

## Problem 2

A delivery route is represented by a string of location categories. Find the longest consecutive segment containing at most three distinct categories.

Constraints:

- the string may contain arbitrary ASCII characters
- n can be 100,000

## Problem 3

You are given an unordered list of prices. You may reorder the list. Return the two original positions whose prices add to a target. If multiple answers exist, return any one.

Constraints:

- values may be as large as 10^9
- original positions must be returned

## Problem 4

A mutable array contains valid records and tombstones represented by -1. Move all valid records to the front in their original order and return the number of valid records. The suffix after that count does not matter.

Constraints:

- the array must be modified in-place
- extra space must be O(1)

## Problem 5

Two independently sorted event feeds contain timestamps. Produce one sorted feed containing every event, preserving duplicates. The feeds may have very different lengths.

Constraints:

- the total number of events is 200,000
- do not concatenate and sort the feeds

## Evaluation Rubric

A strong answer should:

- identify the structural property rather than rely on a trigger word;
- state a correct precondition;
- define state precisely;
- prove the pointer movement;
- distinguish the approach from its closest neighboring pattern;
- give a complexity that includes sorting or heap costs when applicable.

## Retest Rule

After solving, change one constraint and reassess:

- introduce negative values;
- require original ordering;
- change two feeds to k feeds;
- require the window maximum instead of a sum;
- ask for all unique triples instead of one pair.

If the invariant breaks, name the new technique instead of patching the old template.
