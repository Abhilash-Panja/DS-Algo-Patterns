# Two Pointers and Sliding Window - Pattern Summary

## 1. Revision Table

| Pattern | Recognition signal | Core invariant | Main state | Complexity shape | Confused with |
| --- | --- | --- | --- | --- | --- |
| Fixed-size window | every candidate has length k | state describes exactly k contiguous items | running sum or frequency state | O(n) | variable window, prefix sum |
| Variable-size window | longest/shortest feasible region | window state and validity are correct at evaluation | sum, frequency, distinct count | O(n) when monotone | prefix sum + hashmap |
| Sorted opposite pointers | sorted pair/triple or monotone boundary objective | uneliminated answers remain inside pointer interval | left, right, sorted values | O(n) after sorting | hashmap Two Sum |
| Same-direction read/write | remove, compact, filter, move in-place | processed prefix is final output so far | read, write | O(n), O(1) space | partition pointers |
| Multi-sequence merge | two or more sorted sources | next output is among current frontiers | source pointers or heap | O(N + M), or O(N log k) | top-k heap |

## 2. The Five Fingerprints

### Fixed window

~~~text
initialize k items
add one on the right
remove one on the left
evaluate
~~~

### Variable window

~~~text
add right
while invalid or while valid:
    remove left
    move left
evaluate at the correct point
~~~

### Sorted opposite pointers

~~~text
left = first
right = last
compare boundaries
move the side justified by sorted monotonicity
~~~

### Read/write compaction

~~~text
for read:
    if accepted:
        write accepted value
        write++
~~~

### Multi-sequence merge

~~~text
compare current source frontiers
emit the smaller
advance only that source
~~~

## 3. Complexity Roadmap

| Situation | Expected best shape |
| --- | --- |
| fixed contiguous window | O(n) |
| monotone variable window | O(n) |
| unsorted exact pair | O(n) expected with hashmap |
| sorted pair | O(n) if already sorted, O(n log n) if sorting needed |
| two sorted sources | O(N + M) |
| k sorted sources | O(N log k) with heap |
| arbitrary range sums | O(n) preprocessing plus O(1) queries with prefix sums |

## 4. One-Line Memory Hooks

- Fixed window: one leaves, one enters.
- Variable window: grow until useful, shrink until justified.
- Sorted pair: too small means left must rise; too large means right must fall.
- Read/write: read explores; write commits.
- Merge: only current frontiers can be next.
